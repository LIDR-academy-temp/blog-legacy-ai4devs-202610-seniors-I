# Auditoría — feature «Comentarios»

**Alcance:** crear, editar, borrar y listar comentarios, en sus tres capas: API (`backend/start/routes.ts`),
base de datos (migración `comentarios` + semilla) y web (`frontend/src/componentes/Comentarios.jsx`,
`DetallePost.jsx`). Fuera de alcance: posts, autores, categorías y etiquetas, salvo donde muestran o
cuentan comentarios.

**Contraste:** las reglas de negocio del `README.md` (R2: pendiente oculto · R5: recuento solo de
aprobados · R6: sin correo de quien comenta en la respuesta pública).

Ordenados por prioridad (de más a menos grave). Todas las líneas se han leído en el código de esta rama.

5. **C23** — refactor a capas, que absorbe C9, C10, C11.
6. El resto, por orden de tabla.
